# AI司会者 コトネ v0.3.4

個人のWindows PCで、記事・会話から原稿、自然音声、2行以内の字幕付きMP4を作るアプリです。localhost専用です。GitHub・YouTubeへ自動投稿する機能はありません。

## v0.3.4のWindows修正

v0.3.3でWindowsのフォルダー名変更防止テストが失敗した実機報告を受け、ディレクトリを属性読み取りだけでなくFILE_LIST_DIRECTORY付きで開くよう修正しました。FILE_SHARE_DELETEは引き続き許可しません。ジョブと親フォルダーの名前変更拒否、共有違反コード32、解除後の名前変更成功を確認するテストを維持・強化しています。check_windows.batは失敗項目名を表示します。

2026-10-08、利用者のWindows実機でv0.3.4適用後のcheck_windows.batがPASSとなった画面を確認しました。原稿・実API音声生成・MP4出力も完了報告があり、提出された約2分24秒のMP4を全体デコードしてエラーがないことと、冒頭・中盤・末尾の画面を確認しました。音声の自然さ・字幕同期の聴取確認、全Windows環境の検証、独立した第三者認証を意味するものではありません。v0.3.3の実機報告（37件中31成功・1失敗・5未実施）は修正前の履歴です。

## 使い方

1. 古いサーバーを終了し、新しいフォルダーへZIP全体を展開します。既存のフル機能版へ上書きしないでください。
2. 通常の権限でsetup.batを実行します。専用仮想環境にPillow 12.3.0をハッシュ検証して導入し、FFmpeg 9.0.2を指定した配布元からダウンロード・検証します。ネイティブ部品のダウンロードは約109MBです。管理者権限は不要で、アプリの管理者起動は拒否します。
3. check_windows.batを実行します。APIキーなしで回帰テスト、権限、生成物取得、短い動画の作成・デコードを確認します。結果はWINDOWS_CHECK_RESULT.jsonに保存します。ローカルの自己検証結果であり第三者認証ではありません。
4. start.batを実行し、非表示入力欄にOpenAI APIキーを入力します。EnterだけならAPI未接続で起動できます。
5. 自動で開いた画面を使用します。起動用リンクは2分以内・1回限りです。再読み込みは可能です。別タブ・期限切れ時は再起動してください。
6. 記事を貼り「紹介原稿を作る」。記事と原稿を照合し、数値、本人の発言、読み方、個人情報を確認します。
7. 「冒頭だけ声を試す」→「原稿全体の音声を作る」→「MP4を書き出す」。完成物を確認して手動でYouTubeに投稿します。

出力はoutput/に残ります。終了は黒い画面でCtrl+Cです。失敗・中止・再起動でもAPI送信済み分は課金され得ます。

必要環境：Windows 10以降の64bit、対応する64bit Python 3.10〜3.14、ブラウザー、接続と十分な空き容量。通常のローカルNTFSフォルダーを使用してください。共有・クラウド同期・ネットワークフォルダーは避けてください。動画変換ランタイムはWindows x86_64限定です。Linuxでのファイル処理と一部テストは可能ですが、Linux用ランタイムは提供しません。

## データ・費用・安全性

- 記事・会話・読み上げ文をOpenAIに送ります。APIキーはサーバーメモリーに保持し、ブラウザーへ渡しません。OPENAI_API_KEY環境変数は読み込み後に除去します。store:falseは外部へ送らないという意味ではありません。
- POSTはHost・Origin・セッションを検査します。生成物取得にもセッションが必要です。起動用秘密値はURLフラグメント経由で一度交換し、すぐ表示URLから除きます。
- 30回のAPI送信上限と12ジョブ上限は起動ごとに戻ります。永続的な課金上限ではありません。サービス側にも上限を設定してください。
- テロップは最大2行。文字数、読み替え、音声形式・長さ、5分以内の動画を検査します。原稿の正確性や発音を保証するものではありません。
- 出力フォルダーを本人用に制限し、処理中は祖先フォルダーのハンドルを保持します。Windowsはreparse pointと名前変更を制限し、Linuxはno-followのFDを基準に処理します。同じ利用者権限のマルウェアを防ぐサンドボックスではありません。
- 音声開始前に20MiB、MP4開始前に100MiBの余裕を確認します。出力合計500MiB、空き容量512MiB、MP4サイズ100MiBを監視します。失敗した一時MP4は削除し、以前の完成動画と音声を残します。定期検査のため一時的な超過はあり得ます。OSの厳密なクォータではありません。
- HTTP応答にも総時間制限があります。通常30秒、JSON入力後のAPI処理・応答は100秒まで。8接続上限と10秒のI/Oタイムアウトもあります。
- 生の例外、ffmpegの生の診断、Pythonバージョンを通常応答に出しません。ffmpegはシェルを使わず固定引数で実行し、入力形式・プロトコルをrawvideo/pipeとwav/fileに制限します。
- マイクのブラウザー音声認識は、ブラウザーによって外部処理されます。開始時の説明と確認を読んでください。
- 記事からのPrompt Injectionを完全には防げません。モデルにOS・ファイル・任意ネットワーク操作のツールは与えず、投稿前に原稿を確認してください。
